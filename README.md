# React JS - Apuntes y ejercicios

Este repositorio lo armé para ir guardando lo que voy viendo clase a clase en el curso de React JS (Talento Tech).

La idea es usarlo como:

- resumen de teoría
- práctica de ejercicios
- seguimiento de mi progreso

## Estructura

- `clase-01`: primeros pasos con ReactJS, entorno con Vite y primer componente
- `clase-02`: JSX a fondo, props, children, patrón contenedor/presentacional y tipos de export
- `clase-03`: layout en React, estructura de carpetas, CSS Global vs CSS Modules
- `clase-04`: flujo de datos en 3 niveles, eventos y hook useState
- `clase-05`: useEffect, fetch a APIs locales y manejo de estados de carga y error
- `clase-06`: formularios controlados, eventos onChange/onSubmit y subida de imágenes a Imgbb

## Nota

Los ejemplos están organizados por clase y tema para que sea más fácil repasar.
