# Clase 01 - Primeros Pasos con ReactJS

## Temas vistos

- bienvenida y presentación del curso
- repaso de HTML, CSS y JavaScript: qué son y cómo funcionan juntos
- qué es ReactJS: introducción y beneficios (componentización, Virtual DOM, ecosistema)
- la magia de React: Virtual DOM, diffing y reconciliación
- transpilación: cómo Babel convierte JSX a JavaScript estándar
- nociones básicas de la terminal (Windows, macOS y Linux)
- configuración del entorno con Node.js y Vite
- estructura del proyecto generado por Vite (`src/`, `public/`, `index.html`, `package.json`, etc.)
- creando y usando nuestro primer componente funcional con JSX

## Idea principal

En esta primera clase el objetivo fue entender qué lugar ocupa React en el desarrollo web moderno y dejar el entorno listo para trabajar. También vimos cómo se estructura un proyecto con Vite y creamos nuestro primer componente funcional.

## Herramientas mencionadas

- Node.js
- Vite
- Visual Studio Code
- npm

## Comandos usados

```bash
# crear proyecto con Vite
npm create vite@latest

# instalar dependencias
npm install

# levantar servidor de desarrollo
npm run dev
```
